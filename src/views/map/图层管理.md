# 图层管理

## 概述

图层管理页面用于对 eq-fleetcmder-web 项目地图监控中的图层进行统一管理，主要管理内容包括图层样式的配置。

## 背景

地图监控模块（eq-fleetcmder-web）使用 MapLibre 渲染地图，地图由多个图层叠加组成，例如：

- 底图图层（天地图影像等）
- 车辆图层（运输设备、装载设备、辅助设备）
- 线路/区域图层（调度路线、区域边界）
- 其他业务图层

## 管理内容

### 图层样式配置

主要配置项（规划中）：

- 图层显隐（visible）
- 图层顺序（z-index / 渲染顺序）
- 颜色（点、线、面颜色）
- 线宽（line-width）
- 图标样式与旋转
- 透明度（opacity）
- 缩放级别显示范围（min-zoom / max-zoom）
