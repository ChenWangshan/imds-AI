# 图层管理

## 概述

图层管理页面（`/map/layer-management`）用于对 eq-fleetcmder-web 项目地图监控中的图层进行统一管理，主要管理内容包括图层样式的配置。样式在 imds-AI 中配置、预览，保存到数据库后，eq-fleetcmder-web 通过接口获取样式并按样式绘制图层。

## 当前实现（v1）

- 覆盖图层：**基础图层 23 个** + **功能区图层 12 个**（与 eq-fleetcmder-web `src/constant/layers-mapbox.js` 中 `baseLayerDatas`、`jobSite` 子图层一一对应）
- 样式配置：每个子图层（面 polygon / 线 line / 注记 text / 点 circle / 锁定图标 lock / 线填充 lineFill / 箭头 arrow 等）可配置：
  - paint / layout 属性（颜色、透明度、线宽、字号、半径等；表达式支持 JSON 编辑与「改为固定值」）
  - 显示开关、minzoom / maxzoom
- 预览：MapLibre GL 渲染，支持**单图层预览**、**全图层预览**（勾选图层集合），数据经 `/eqfleet` 代理实时拉取 eq-fleetcmder-web 网关
- 持久化：配置暂存 localStorage；「导出 JSON」可产出供后端/eq 消费的 styleMap 结构

## 使用方式

1. 打开 eq-fleetcmder-web（http://localhost:8989）控制台，执行 `localStorage.getItem('eq-token')` 获取 token，填入页面
2. 填写 orgId（及 userOrgId），点击「加载矿区」选择 mapId
3. 左侧选择图层 → 右侧配置样式 → 点击「单图层预览」/「全图层预览」
4. 点击「保存配置」（本地缓存）/「导出 JSON」

### 图层数据结构（layers-mapbox.js）

- 每图层：`id`/`name`/`label`/`type`/`checked`/`display`/`roles`/`wsCode`/`styleMap`/`addFn`/`renderFn`/`toggleFn`
- `styleMap` key 为子样式类型，value 为 Mapbox 图层描述：`filter`、`paint`（fill-color/line-color 等，支持 match/case/interpolate 表达式）、`layout`、`minzoom`/`maxzoom`
- `baseLayerDatas` 每层含 `mvtName`/`jsonName`（LOAD_AREA、UNLOAD_AREA、LANE 等）、`code`（WS 码）、`featureType`、`initBatchGroup`（初始化合并请求分组）

### 数据接口（网关 https://gateway-test12.eqfleetcmder.com，header 带 token）

| 图层 | 接口 | 参数 |
| --- | --- | --- |
| 基础图层 | POST `/geoserverLayer/queryMapDataByType` | `{ mapId, code: [jsonName...] }` → `data[jsonName]` FeatureCollection |
| 破碎位/装载位/加油位/破碎口/破碎场 | POST `/v1/mapBiz/listMapBizElement` | `{ mapId, orgId, mapInfoType }` → `data.mapElementDetail[]` |
| 卸载位/停车位/堆排区 | POST `/v1/mapBiz/listMapBizElementForMonitor` | 同上 |
| 临时卸载位 | POST `/v1/temporaryUnloadArea/list` | `{ mapId, orgId, userOrgId }` → `data[]` |
| 排队位/临时停车位 | POST `/v1/functional/listFunctionalPositions` | `{ orgId, userOrgId, type: 1|2 }` → `data[]` |
| 轨迹指引 | POST `/v1/functional/listAvailableFunctionalPositions` | `{ types: [3,4], mapId }` → `data[]` |
| 矿区列表 | POST `/v1/mineArea/queryMineAreaList` | `{ equal: { orgId } }` → `data[]`（含 mapId） |
